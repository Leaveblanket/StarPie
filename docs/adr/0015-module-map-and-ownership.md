# 模块划分共识：12 模块地图、归属裁定与修整单元判据

> Status: Active（决策 3 被 0016、判据被 0023 修订）
>
> 决策 3（结构形态：概念模块 + 端口）被 [ADR-0016](./0016-assembly-split-target-and-roadmap.md) 升级为程序集化；共享内核放行/契约归属判据被 [ADR-0023](./0023-module-contracts-hard-boundary-and-core-narrowing.md) 修订。
> 模块地图正典：[modules.md](../architecture/modules.md)（本 ADR 为决策依据，现状以 modules.md 为准）。

## 动机

模块化路线需要定稿：目标模块怎么划分、类型归属如何裁定、什么算“独立/可模块化”。此前归属靠文档盘点与个人判断，无统一判据。

## Considered Options

- **判据：二值“有叶子即独立”**：文档盘点价值低；选 **修整单元判据**——模块 = 领域能力，加/改功能只动相关模块内部，跨模块只经稳定契约或放行共享面。
- **结构形态：概念模块 + 端口（保持水平目录）** vs **垂直模块目录 / 独立程序集**：当时选概念模块 + 端口（文档级归属 + 契约边界），后被 ADR-0016 升级为程序集化。
- **配置方案是否独立成模块**：否决——新增动作类型会同时穿“动作执行”与“配置方案编辑”两个模块，配置方案设置面必须与动作执行同在 M1。
- **界面主题是否升层**：采纳升为顶层 M4（独立设置子 VM、消息化、多窗口消费方，壳层叶已滞后）。
- **本地化与消息是否合并**：否决维持合并——两者无共享上下文、无耦合，属“文档分组惯性”反例；拆为 S3 本地化 + S4 消息与通知。
- **IconHelper 归属**：三分（R6）——图标资产 → S1、几何（唯一消费方是轮盘）→ M2、程序侧 → M3；几何不属共享。
- **消息类型归属**：选中心 hub——`Services/Messages` 保留为跨模块事件契约 hub，新消息类型 = 放行共享面；按域归属代价是目录/命名空间正典迁移。

## Decision

1. **判据**：模块 = 领域能力；验收基准 = “修改/新增功能只动相关模块内部”，以 [extending.md](../architecture/extending.md) 原型 A–F 为验收样例。
2. **目标模块地图（12）**：M1 手势与动作、M2 轮盘与渲染、M3 程序扫描与目录、M4 界面主题、M5 壳层与系统集成；S1 图标资产、S2 配置与保存、S3 本地化、S4 消息与通知、S5 导航、S6 对话框；H1 宿主与组合根。职责与关键内部见 modules.md §3。
3. **结构形态**：概念模块 + 端口，保持 `Services/ViewModels/Views/Models` 水平目录正典（已被 ADR-0016 修订为程序集化）。
4. **共享内核放行清单**：config 模型字段、i18n 键、Composition/导航登记一次、消息与通知 hub 新类型、共享视图基础设施、共享图标资产——不算“其它业务模块内部”（清单后续收窄：共享 UI 去共享化、模块出口契约下沉 `*.Contracts`，见 [ADR-0023](./0023-module-contracts-hard-boundary-and-core-narrowing.md)）。
5. **配置方案设置面并入手势与动作（M1）**：不单独成模；M1 内部登记三个子面。
6. **界面主题升为顶层模块（M4）**；**消息 hub 保留（S4）**：新增消息类型为放行共享面；本地化与消息在文档层拆为 S3/S4。
7. **归属裁定 R1–R8 与登记 D1–D6 采纳**（modules.md §4/§5；R4/D3 后被 ADR-0016 及后续修订）。
8. **页面壳原则**：页面 = 聚合壳；配置面按卡片/子 VM 归模块。

## Consequences

- [modules.md](../architecture/modules.md) 为模块地图与归属正典；本 ADR 只解释“为什么这样划分”。
- CONTEXT 不收录模块名（“界面主题模块”“修整单元”是架构术语而非领域术语，ADR-0014 先例）。
- 本 ADR 不推翻 ADR-0005（DI/消息总线）、0011（Composition/AppHost 拆分）、0013（本地化/主题）、0014（轮盘配色归属与外观拆分）；0014 的“界面主题模块”正名由本 ADR 收口为 12 模块地图中的 M4。
